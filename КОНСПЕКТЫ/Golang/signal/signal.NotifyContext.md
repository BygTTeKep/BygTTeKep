Возвращает **контекст, который отменяется при получении сигнала**.

```go
ctx, stop := signal.NotifyContext(context.Background(), syscall.SIGINT, syscall.SIGTERM)
defer stop() // обязательно: снимает подписку и освобождает ресурсы

<-ctx.Done() // ждём сигнал
log.Println("останавливаемся:", ctx.Err()) // context canceled
```

Это обёртка над `Notify` + `WithCancel`: внутри создаётся канал и горутина, которые при сигнале вызывают отмену контекста.

Плюс этот ctx можно **сразу передавать дальше**: в воркеры, HTTP-запросы, запросы к БД, `errgroup`. Все они узнают об остановке через привычный `ctx.Done()`.

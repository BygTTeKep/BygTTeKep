### `signal.Notify`: через канал

Вы создаёте канал, и пакет `os/signal` присылает в него сигналы.

```go
sigCh := make(chan os.Signal, 1) // буфер минимум 1, иначе сигнал можно потерять
signal.Notify(sigCh, syscall.SIGINT, syscall.SIGTERM)

go func() {
    sig := <-sigCh
    log.Println("получен сигнал:", sig)
    // начинаем остановку
}()
```

Особенности:

- **Канал нужен буферизованный.** Пакет не блокируется при отправке: если читатель не готов, а буфера нет, сигнал отбрасывается.
- Можно узнать, **какой именно** сигнал пришёл (`sig`).
- Для отмены подписки есть `signal.Stop(sigCh)`.
- Чтобы остановить остальной код, вы сами должны превратить сигнал в отмену: вызвать `cancel()` или закрыть канал.
- Без аргументов (`signal.Notify(sigCh)`) подписывает на **все** сигналы.

Наследование: отношение является(is a): Child это подтип Base, его можно подставить везде где ждут Base, и переопределенные методы определяется по рельному типу в рантайме

Встраивание: это композиция(has a, содержит). Поля и методы вложенной структуры поднимаются наверх. Но одну структуру нельзя заменить другой структурой, если они имеют разные методы

```ts
class Base {
  hello() { return this.name(); }
  name() { return 'base'; }
}
class Child extends Base {
  name() { return 'child'; }
}

new Child().hello(); // 'child'
```

```go
type Base struct{}

func (b Base) Hello() string { return b.Name() }
func (b Base) Name() string  { return "base" }

type Child struct{ Base }

func (c Child) Name() string { return "child" }

Child{}.Hello() // "base" !
```

Выбор метода в Go делается **на этапе компиляции по статическому типу выражения слева от точки**. В JS он делается **в рантайме по реальному объекту (`this`)**.

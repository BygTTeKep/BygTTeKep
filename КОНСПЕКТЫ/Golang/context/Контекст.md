Контекст - это объект который позволяет управлять временем жизни операций и проброса сквозных сигналов между слоями приложения
```go
type Context interface {
    Deadline() (deadline time.Time, ok bool)
    Done() <-chan struct{}   // закрывается при отмене или истечении времени
    Err() error              // почему закрыт: Canceled или DeadlineExceeded
    Value(key any) any
}
```

**Зачем нужен:**

- Остановить работу, когда результат уже не нужен (клиент отключился, запрос отменён).
- Ограничить время операции (запрос в БД, вызов внешнего API).
- Не допустить утечек горутин: они видят `ctx.Done()` и завершаются.
- Передать данные уровня запроса (request ID, trace ID, пользователь).

Любой контекст должен наследоваться от какогото другого контекста исключение `context.Background` и `context.TODO`

`context.Background` - это контекст заглушка, используемый, как правило, для всех дочерних контекстов

`context.TODO` - это тоже заглушка но используется когда мы еще не определились с типом контекста

### Производные контексты

```go
// WithCancel: отмена вручную
ctx, cancel := context.WithCancel(parent)
defer cancel()

// WithTimeout: отмена через промежуток времени
ctx, cancel := context.WithTimeout(parent, 2*time.Second)
defer cancel()

// WithDeadline: отмена в конкретный момент
ctx, cancel := context.WithDeadline(parent, time.Now().Add(2*time.Second))
defer cancel()

// WithValue: добавляет пару ключ-значение
ctx := context.WithValue(parent, requestIDKey{}, "abc-123")
```

`WithTimeout(parent, d)` это просто `WithDeadline(parent, time.Now().Add(d))`.

**`cancel()` нужно вызывать всегда**, даже если контекст закончится сам по таймеру: иначе до истечения времени будут удерживаться ресурсы (таймер, запись в родителе). `go vet` (`lostcancel`) ловит забытый `cancel`. Вызов `cancel` можно делать многократно, повторные вызовы ничего не делают.

### Как использовать в коде
```go
func fetch(ctx context.Context, url string) error {
    req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
    if err != nil {
        return err
    }
    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        return err // при отмене вернётся ошибка, оборачивающая context.Canceled/DeadlineExceeded
    }
    defer resp.Body.Close()
    return nil
}
```

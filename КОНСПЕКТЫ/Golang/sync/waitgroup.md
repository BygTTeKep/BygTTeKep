### `sync.WaitGroup`

Ждёт завершения группы горутин. Внутри счётчик.

- `Add(n)` увеличивает счётчик
- `Done()` уменьшает на 1 (то же, что `Add(-1)`)
- `Wait()` блокируется, пока счётчик не станет 0

```go
var wg sync.WaitGroup

for _, url := range urls {
    wg.Add(1)
    go func() {
        defer wg.Done()
        fetch(url)
    }()
}

wg.Wait()
```

С Go 1.25 есть удобный `wg.Go(func() { ... })`, который сам делает `Add(1)` и `defer Done()`.

**Ловушки:**

- `Add` нужно вызывать **до** запуска горутины, а не внутри неё: иначе `Wait` может проскочить раньше.
- Счётчик ушёл в минус: паника `negative WaitGroup counter`.
- Копирование `WaitGroup` (передача по значению) ломает логику, передавайте `*sync.WaitGroup`.
- `WaitGroup` не собирает ошибки и не отменяет остальных. Для этого есть `errgroup`.

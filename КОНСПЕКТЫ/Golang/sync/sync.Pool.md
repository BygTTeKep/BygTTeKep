Пул **временных объектов** для повторного использования, чтобы уменьшить число аллокаций и нагрузку на GC.

```go
var bufPool = sync.Pool{
    New: func() any { return new(bytes.Buffer) },
}

func render() string {
    buf := bufPool.Get().(*bytes.Buffer)
    defer bufPool.Put(buf)
    buf.Reset() // обязательно очистить перед использованием

    buf.WriteString("hello")
    return buf.String()
}
```

- `Get()` берёт объект из пула или вызывает `New`, если пул пуст.
- `Put(x)` возвращает объект.
- Потокобезопасен, внутри использует локальные для каждого `P` кэши, поэтому быстрый.

**Важно:**

- **Содержимое пула может быть очищено в любой момент**, обычно при GC (с двухэтапной очисткой через victim cache). Нельзя хранить в пуле то, что должно жить долго (соединения, состояние).
- Нет гарантии, что `Get` вернёт тот объект, который вы клали.
- Объект перед `Put` нужно **сбросить** в чистое состояние, а после `Put` им **нельзя пользоваться**.
- Не помещайте в пул очень разнородные по размеру объекты (буфер, раздувшийся до гигабайта, будет висеть в пуле). Так делают, например, `fmt` и `encoding/json`.
- Выигрыш есть только для часто создаваемых объектов; измеряйте бенчмарком.
- Хранение значений не-указателей (например, слайс) в `any` само вызывает аллокацию, поэтому кладут указатели.

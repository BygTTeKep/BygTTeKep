### `sync.Mutex`

Взаимное исключение: в критической секции находится только одна горутина.

```go
type Counter struct {
    mu sync.Mutex
    n  int
}

func (c *Counter) Inc() {
    c.mu.Lock()
    defer c.mu.Unlock()
    c.n++
}
```

- `Lock()` / `Unlock()`, `TryLock()` (Go 1.18, использовать редко).
- Zero value готов к работе (разблокированный).
- Мьютекс **не привязан к горутине**: разблокировать может другая, но так делать не стоит.

**Ловушки:**

- Забытый `Unlock` приводит к deadlock, поэтому `defer mu.Unlock()` сразу после `Lock()`.
- **Повторный `Lock` в той же горутине** вызывает deadlock: мьютекс **не рекурсивный**.
- `Unlock` незалоченного мьютекса: fatal error.
- Мьютекс хранят приватным полем и не встраивают в структуру (иначе `Lock` становится публичным методом).
- Не держать мьютекс во время медленных операций (сеть, диск).
- Методы структуры с мьютексом должны быть с pointer receiver.

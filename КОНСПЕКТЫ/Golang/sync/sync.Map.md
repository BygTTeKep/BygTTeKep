Потокобезопасная map без внешней блокировки. Ключи и значения типа `any`.

```go
var m sync.Map

m.Store("a", 1)
v, ok := m.Load("a")
actual, loaded := m.LoadOrStore("b", 2)
m.Delete("a")
v, loaded = m.LoadAndDelete("b")
m.Range(func(k, v any) bool {
    fmt.Println(k, v)
    return true // false останавливает обход
})
```

Дополнительно: `Swap`, `CompareAndSwap`, `CompareAndDelete`, `Clear` (Go 1.23).

**Когда подходит** (из документации):

1. Ключ записывается один раз, а читается много раз (кэши, которые только растут).
2. Горутины работают с **непересекающимися наборами ключей**.

В остальных случаях **`map` + `Mutex`/`RWMutex`** обычно проще и быстрее. Причины: `sync.Map` не типобезопасна (нужны type assertions), нет `len`, оптимизирована под узкие сценарии. Для типобезопасности используют обёртку на дженериках или обычную map под мьютексом.

Внутри два слоя: read-only карта для быстрых чтений без блокировок и «грязная» карта под мьютексом для новых записей. Начиная с Go 1.24 реализация переписана на основе HAMT (concurrent hash-trie), поведение для пользователя то же.

**Ловушки:**

- `Range` не гарантирует снимок: при параллельных изменениях может увидеть или не увидеть новые записи.
- Атомарность составных операций (проверить и записать) обеспечивают только `LoadOrStore`, `CompareAndSwap` и подобные, а не пара `Load` + `Store`.

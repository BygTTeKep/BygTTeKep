Это примитив синхроназации который гарантирует что функция будет вызвана только 1 раз
Гарантирует, что функция выполнится **ровно один раз**, даже при конкурентных вызовах. Остальные вызывающие ждут завершения первого.
пример
```go
var once sync.Once

func initConfig(){
	fmt.Println("init config")
}

func main(){
	for i:=0; i<5; i++ {
		go func(){
			once.Do(initCOnfig)
		}
	}
	select{}
}
```
В примере выше "initConfig" выведится только 1 раз

Типичное применение: ленивая инициализация синглтона, одноразовая настройка.

**Нюансы:**

- Если функция в `Do` **паникует**, `Do` всё равно считает её выполненной, повторно она не вызовется.
- **Повторный `once.Do` внутри `Do`** того же `Once` приводит к deadlock.
- Ошибку внутри `Do` не вернуть напрямую; сохраняют в переменную.
- Помощники (Go 1.21): `sync.OnceFunc(f)`, `sync.OnceValue(f)`, `sync.OnceValues(f)` возвращают функцию, которая выполняет `f` один раз и кэширует результат (и ошибку).

```go
getConfig := sync.OnceValues(func() (*Config, error) {
    return loadConfig()
})
cfg, err := getConfig()
```

slice - это динамическое окно над массивом, Длина не входит в тип
при копировании делит данные с оригиналом
Слайс это маленькая структура из 3 полей

```go
type slice stuct {
	ptr *T
	len int
	cap int
}
```

ptr - указатель на первый элемент массива
Len - сколько элементов доступно
cap - сколкьо всего места от Ptr До конца

Срез 
```go
s[i;j]
создает новыый слайс над тем же массивом
len = j-i
cap = cap(s) -i 
```

что делает append 
Если len < cap: элемент пишется в существующий массив len увеличивается
Если len > cap: Выделяется новый массив, данные копируются слас указывает на новый массив
**Результат `append` всегда нужно присваивать:** `s = append(s, x)`.

**Общий массив приводит к неожиданным эффектам:**


```go
a := []int{1, 2, 3, 4}
b := a[:2]           // len 2, cap 4
b = append(b, 99)    // cap хватает: перезаписывает a[2]!
fmt.Println(a)       // [1 2 99 4]
```

Защита: полный срез `a[:2:2]` (ограничивает cap) или явное копирование через `copy`.

**Утечка памяти:** маленький срез от огромного массива удерживает весь массив. Решение: скопировать нужную часть в новый слайс.

**Передача в функцию:** дескриптор копируется, но указатель на массив тот же. Изменение элементов видно снаружи, а `append` внутри функции снаружи виден не будет (len внешнего слайса не изменился).

**Preallocate:** если размер известен, `make([]T, 0, n)` избавляет от лишних реаллокаций.

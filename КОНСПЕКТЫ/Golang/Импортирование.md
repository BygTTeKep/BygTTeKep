В go нет ключевых слов public private

Импортированость определяется первой буквой, если первая буква заглавная то имя импортируемо, если с маленькой буквы то имя не импортированно и видно в рамках пакета

Правило действует для всего: функций, переменных, полей структур, методов
### Важные нюансы

**Граница это пакет, а не файл и не тип.** Все файлы одного пакета видят приватные имена друг друга. Это отличается от `private` в Java/C#, где приватность привязана к классу.

**Поля структур и JSON.** Пакет `encoding/json` (как и любой другой пакет, использующий `reflect`) не видит неэкспортируемые поля, поэтому они **не попадут в JSON**:


```go
type User struct {
    Name  string `json:"name"`
    email string // будет проигнорировано при Marshal
}
```
**Директория `internal/`.** Это дополнительный уровень ограничения: пакеты внутри `internal` могут импортироваться только из родительского дерева каталогов. Так скрывают код от внешних проектов, даже если имена в нём экспортируемые.

**Исключения из правила про заглавную букву:** символы, для которых нет регистра (например, иероглифы), считаются неэкспортируемыми. Имена пакетов и локальные переменные внутри функций к экспорту не относятся.

`ServeHTTP` - это точка входа для одного http запроса 
ServeHTTP перенаправляет запрос обработчику, чей шаблон наиболее точно соответствует URL-адресу запроса.
### Что происходит при запросе

1. `http.Server` принимает TCP-соединение.
2. Читает и разбирает HTTP-запрос в структуру `*http.Request`.
3. Создаёт `http.ResponseWriter`, через него пишется ответ.
4. Вызывает `handler.ServeHTTP(w, r)` у того хендлера, что указан в `Server.Handler`.
5. Когда метод вернулся, ответ считается законченным и отправляется клиенту.

Каждый запрос обрабатывается в **своей горутине**, поэтому `ServeHTTP` вызывается конкурентно, и общее состояние внутри хендлера нужно защищать (мьютекс, атомики и т.п.).

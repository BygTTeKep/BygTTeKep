`ServeMux`  это роутер(мультиплексор) Он хранит таблицу «паттерн → хендлер» и для каждого входящего запроса выбирает, какой хендлер вызвать. Само имя расшифровывается как _HTTP request multiplexer_.

Когда приходит запрос, вызывается `mux.ServeHTTP(w, r)`. Внутри он:

1. Смотрит на метод и путь запроса.
2. Ищет подходящий паттерн среди зарегистрированных.
3. Если нашёл, кладёт значения wildcard-ов в запрос (потом достаёшь через `r.PathValue("id")`) и вызывает `ServeHTTP` найденного хендлера.
4. Если не нашёл, отвечает `404 Not Found`. Если путь есть, но метод не тот, отвечает `405 Method Not Allowed` с заголовком `Allow`.

### Какие бывают паттерны (Go 1.22+)

| Паттерн             | Значение                                             |
| ------------------- | ---------------------------------------------------- |
| `/health`           | точное совпадение пути                               |
| `GET /events`       | только метод GET                                     |
| `/files/`           | со слэшем на конце: всё поддерево (`/files/a/b.txt`) |
| `/files/{$}`        | только сам `/files/`, без поддерева                  |
| `GET /users/{id}`   | wildcard, значение в `r.PathValue("id")`             |
| `/static/{path...}` | wildcard, захватывающий остаток пути                 |
| `example.com/api`   | можно привязать к хосту                              |

Struct tags - это строковая метаинформация у поля структуры. Сам компилятор ее не использует, она читается другими пакетами через reflect

```go
type User struct {
    ID       int    `json:"id"`
    Name     string `json:"name"`
    Email    string `json:"email,omitempty"`
    Password string `json:"-"`
    Age      int    `json:"age,string" db:"user_age" validate:"gte=0,lte=150"`
}
```
Формат: строка в обратных кавычках, внутри пары `ключ:"значение"`, разделённые **пробелом** (не запятой). Один тег может содержать несколько ключей для разных библиотек.

### Что умеет json

- `json:"name"` задаёт имя поля в JSON.
- `omitempty` пропускает поле, если оно пустое (`0`, `""`, `false`, `nil`, пустой слайс/map). Для структур не работает (в Go 1.24 добавлен `omitzero`, учитывающий zero value, включая структуры и `time.Time`).
- `json:"-"` полностью исключает поле.
- `,string` кодирует число/bool как строку в JSON.
- Без тега используется имя поля как есть (`ID`, `Name`), а неэкспортируемые поля (со строчной буквы) игнорируются всегда.

Другие популярные теги: `db` (sqlx), `gorm`, `yaml`, `xml`, `validate` (validator), `env`, `mapstructure`, `form`, `binding` (gin).

```go
t := reflect.TypeOf(User{})
field, _ := t.FieldByName("Email")

fmt.Println(field.Tag)                   // json:"email,omitempty"
fmt.Println(field.Tag.Get("json"))       // email,omitempty

v, ok := field.Tag.Lookup("db")          // ok == false, если ключа нет
```
- `Tag.Get(key)` возвращает значение или пустую строку.
- `Tag.Lookup(key)` возвращает значение и флаг наличия (позволяет отличить `json:""` от отсутствия ключа).
Обход всех полей:

```go
t := reflect.TypeOf(User{})
for i := 0; i < t.NumField(); i++ {
    f := t.Field(i)
    fmt.Printf("%s -> json=%q\n", f.Name, f.Tag.Get("json"))
}
```

Принцип работы библиотек: получают тип через `reflect`, обходят поля, читают нужный ключ тега, разбирают значение (обычно `strings.Split` по запятой: первое значение это имя, остальные опции) и на его основе кодируют/декодируют/валидируют.

### Ловушки

- **Синтаксис не проверяется компилятором.** Опечатка (`json: "name"` с пробелом после двоеточия, или запятая между ключами) молча приводит к тому, что тег игнорируется. `go vet` (проверка `structtag`) такое ловит.
- **Неэкспортируемое поле с тегом бесполезно**: `reflect` видит поле, но `json` не может в него писать.
- **`omitempty` и указатели:** `*int` с `omitempty` пропустит только `nil`, а указатель на `0` будет выведен. Поэтому для «необязательных, но допустимо нулевых» значений используют указатели.
- **Теги не наследуются** при встраивании: у встроенной структуры они работают на её собственных полях.

# Коротко
**Struct tags** это метаданные поля в виде строки `key:"value"`, читаются в рантайме через `reflect.StructField.Tag.Get/Lookup`. Компилятор их не проверяет, поэтому нужен `go vet`. Основное применение: `json`, `db`, `yaml`, `validate`.

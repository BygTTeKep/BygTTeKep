Тесты лежат в файлах `*_test.go` рядом с кодом. Функция называется `TestXxx` и принимает `*testing.T`. Отдельного фреймворка не нужно, всё в стандартной библиотеке.

```go
// sum.go
func Sum(a, b int) int { return a + b }

// sum_test.go
func TestSum(t *testing.T) {
    got := Sum(2, 3)
    if got != 5 {
        t.Errorf("Sum(2, 3) = %d, want %d", got, 5)
    }
}
```


```bash
go test ./...            # все пакеты
go test -v ./...         # подробный вывод
go test -run TestSum     # по имени (регулярное выражение)
go test -race ./...      # с детектором гонок
go test -cover ./...     # покрытие
go test -count=1 ./...   # без кэша результатов
```

Пакет тестов: `package foo` (белый ящик, видны приватные имена) или `package foo_test` (чёрный ящик, только публичный API, ближе к реальному использованию).

### Основные методы `*testing.T`

|Метод|Поведение|
|---|---|
|`t.Errorf` / `t.Error`|пометить тест упавшим, **продолжить**|
|`t.Fatalf` / `t.Fatal`|пометить упавшим и **остановить** этот тест|
|`t.Log` / `t.Logf`|вывод (виден при `-v` или падении)|
|`t.Skip`|пропустить тест|
|`t.Helper()`|вспомогательная функция: ошибка укажет на строку вызывающего|
|`t.Cleanup(f)`|отложенная очистка (как `defer`, но работает и для подтестов)|
|`t.TempDir()`|временная директория, удаляется автоматически|
|`t.Setenv`|переменная окружения на время теста|
|`t.Parallel()`|запускать параллельно с другими такими тестами|

`Fatal` нельзя вызывать из другой горутины (только `Error`, иначе поведение некорректно).

init - это специальная функция которая вызывается до mian
Вызвать вручную ее не получится, используется для настройки состояния пакета, регистрация драйверов, проверка конфигураций, заполнение таблиц

Не принимает ничего и не отдает ничего
В одном файле, пакете может быть несколько init

# Порядок инициализации
Переменные уровня пакета инициализируются с учетом зависимостей между ними, затем вызываются все Init пакета

Для нескольких пакетов
Сначало полностью инициализируютсыя все импортируемые пакеты (рекурсивно, зависимости идут первыми)

Каждый пакет инициализируется один раз даже если импортируют многие

Последним инициализируется main после чего вызывается Main.main

Цепочка если main импортирует A, а A импортирует B, то порядок такой: B(переменные, init) -> A(переменные, init) -> main(переменные, intit) -> main()

Внутри пакета файлы компилятору обычно передаются в алфавитном порядке (так делает go build()) init вызываются в порядке следования файлов и в порядке написания 

Частый импортпатерн Blank import для того чтобы инициализировать init()
```go
import _ "github.com/lib/pq"
```

Массивы являются не ссылочными типами данных, а просто значение, это значит что если мы просто присвоем значение переменной другого массива, а потом попытаемся его поменять, изначальный массив не изменится

```go
package main
import "fmt"
func arr() {
    ar := [3]int{1, 2, 3}
    br := ar
    br[1] = 0
    fmt.Println(ar) // 1,2,3
    fmt.Println(br) // 1, 0, 3
}
func main() {
    arr()
}
```

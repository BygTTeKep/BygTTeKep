string  - это неизменяемая последовательность байт
внутри дескриптор из 2 полей

```go
type string struct {
	ptr *byte
	len int
}
```

len возращает число баййт а не символов
Строку нельзя измениьт, любое изменение создает новую стркоу
Строки можно сравнивать, конкатенировать, деать срезы без копирования данных, оба указывают на одну память
Zero value: `""` (не nil, у строки nil быть не может).
Строка не обязана быть валидным UTF-8, это просто байты. Но литералы в исходниках всегда UTF-8.

### byte и rune
- **`byte`** это алиас `uint8`. Один байт.
- **`rune`** это алиас `int32`. Один **Unicode code point** (кодовая точка).

### Индексация и range

Индекс возвращает **байт**, `range` идёт по **рунам**:

```go
s := "Привет"
fmt.Println(s[0])        // 208 (первый байт буквы 'П', а не сама буква)

for i, r := range s {
    fmt.Println(i, string(r))
}
// 0 П, 2 р, 4 и, 6 в, 8 е, 10 т
// i это байтовое смещение начала руны (шаг 2), r это rune
```

Если в строке встретится невалидная последовательность, `range` выдаст руну `utf8.RuneError` (`U+FFFD`) и сдвинется на 1 байт.

### Конвертации

```go
[]byte(s)   // копия байт строки
[]rune(s)   // декодирует UTF-8 в руны (копия)
string(bs)  // из []byte (копия)
string(rs)  // из []rune
string(r)   // из rune -> строка с этим символом
```

Ловушка: `string(65)` даст `"A"` (число трактуется как code point), а не `"65"`. Для числа используйте `strconv.Itoa`. `go vet` на это ругается.

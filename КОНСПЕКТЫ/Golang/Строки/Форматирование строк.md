```go
fmt.Sprintf() // Возращает строку
fmt.Printf() // пишет в stdout
fmt.Fprintf() // пишет в io.writer
fmt.Errorf() // создает error поддерживает %w
```

%w - это специальный глагол который оборачивает ошибку в текст, сама ошибка сохраняется внутри новой. Это значит что при error.Unwrap достается 
%v - значение в формате по умолчанию
%T - Тип значения
%d - целое число
%t - bool
%p - адрес указателя

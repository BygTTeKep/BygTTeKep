### `Prepare`: подготовленный запрос

Запрос разбирается и планируется на сервере один раз, затем выполняется много раз с разными параметрами.

```go
stmt, err := db.PrepareContext(ctx, "INSERT INTO logs(msg) VALUES($1)")
if err != nil {
    return err
}
defer stmt.Close()

for _, m := range msgs {
    if _, err := stmt.ExecContext(ctx, m); err != nil {
        return err
    }
}
```

Нюансы:

- `Stmt` привязан к пулу: под капотом готовится на нужном соединении и при необходимости переподготавливается на другом.
- Не забывайте `stmt.Close()`.
- Для одиночного запроса `Prepare` не нужен: драйверы часто сами делают подготовку при передаче параметров, а лишний вызов добавляет круг до сервера.
- Выигрыш есть при большом числе повторений одного запроса (в транзакции: `tx.Prepare`).
